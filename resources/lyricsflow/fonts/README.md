`minecraft` is a stand-in. For the real Minecraft font, on the PC run
`python tools/LyricsFonts/make_fonts.py --out resources/lyricsflow/fonts --default8 "<game>/data/resource_packs/vanilla/font/default8.png"`
(that file is Mojang's: generate locally, never commit it). The other 14 LyricsFlow fonts can be added with `--fonts <id>`
after copying their TTF + licence from the v2.0 jar. Preview any atlas without the game:
`python tools/LyricsFonts/preview.py resources/lyricsflow/fonts preview.png` (same SDF maths as shaders/glyph.hlsl).

## cjk_jp
Japanese fallback (kana, CJK punctuation, fullwidth forms, the 2965 JIS level-1 kanji) from Noto Sans JP Bold
(Sans2.004, SIL OFL 1.1, see LICENSE_NotoSansJP.txt), built with make_fonts.build(em 40, ss 3, range 6, width 4096).
Any lyric font falls back to it for glyphs it lacks (FontSet::linkFallbacks).
