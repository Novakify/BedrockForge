# LyricsFlow port - glyph atlases

Generated by `tools/LyricsFonts/make_fonts.py` (do not edit by hand). Each font = `<id>.png` (atlas) + `<id>.json`
(msdf-atlas-gen layout: atlas type/size/distanceRange, metrics, per-glyph advance + planeBounds + atlasBounds).

| id | type | source (licence in third_party/lyricsflow/fonts) | used by |
|---|---|---|---|
| lyricsflow_script | SDF | LyricsFlow Script (OFL) | LyricsFlow default font |
| greatvibes | SDF | Great Vibes (OFL) | Aurora Cursive (video B) |
| kaushan | SDF | Kaushan Script (OFL) | Neon Arena (video C) |
| outfit, outfit_bold | SDF | Outfit (OFL) | top bar / clean text |
| poppins | SDF | Poppins (OFL) | clean text |
| pacifico, dancing | SDF | Pacifico, Dancing Script (OFL) | extra script looks |
| minecraft | bitmap | **placeholder**: Pixelify Sans (OFL) | Ground Drop (A), Wall Gold (D) |

`minecraft` is a stand-in. For the real Minecraft font, on the PC run
`python tools/LyricsFonts/make_fonts.py --out resources/lyricsflow/fonts --default8 "<game>/data/resource_packs/vanilla/font/default8.png"`
(that file is Mojang's: generate locally, never commit it). The other 14 LyricsFlow fonts can be added with `--fonts <id>`
after copying their TTF + licence from the v2.0 jar. Preview any atlas without the game:
`python tools/LyricsFonts/preview.py resources/lyricsflow/fonts preview.png` (same SDF maths as shaders/glyph.hlsl).
